# 🎮 ESP32-S3 Twitch Drops Farmer

Автономний фармер **Twitch Drops** на платі **ESP32-S3**, який працює без участі ПК за аналогією з популярним софтом [TwitchDropsMiner](https://github.com/DevilXD/TwitchDropsMiner).

Мікроконтролер самостійно підключається до Wi-Fi, підтримує активну WebSocket-сесію з Twitch PubSub, імітує перегляд стримів і автоматично забирає (Claim) отримані нагороди.

---

## 🌟 Основні можливості

- **Повна підтримка Twitch PubSub WebSockets (`wss://pubsub-edge.twitch.tv/v1`)**: Підписка на топіки відтворення стриму та подій дропів для стабільного зарахування хвилин перегляду.
- **Автоматичний пошук стримерів**: Знаходить активні трансляції для обраної гри з увімкненими Drops.
- **Підтримка конкретного стримера**: Можливість вказати точний нікнейм стримера для фарму.
- **Автоматичне затребування нагород (Auto-Claim)**: Авто-збір дропів при досягненні 100% прогресу.
- **Вбудований Web-панель керування**: Зручний веб-інтерфейс для налаштувань, перегляду логів та статистики у реальному часі.
- **Captive Portal / AP Mode**: Якщо Wi-Fi не налаштований, ESP32 створює точку доступу `ESP32-Twitch-Farmer` для швидкої конфігурації.
- **USB CDC Serial CLI**: Керування та діагностика через Serial-монітор (115200 baud).

## 🔑 Як отримати Twitch OAuth Токен (`auth-token`)

Для роботи фармера потрібен свій `auth-token` з акаунта Twitch:

1. Відкрийте браузер (Chrome, Edge, Firefox) і увійдіть на [Twitch.tv](https://www.twitch.tv).
2. Натисніть **F12** (або ПКМ -> *Дослідити елемент*), щоб відкрити Інструменти розробника.
3. Перейдіть на вкладку **Application** (в Firefox: *Сховище* / *Storage*).
4. У лівому меню розгорніть **Cookies** та виберіть `https://www.twitch.tv`.
5. Знайдіть у списку ключ **`auth-token`**.
6. Скопіюйте його значення (рядок із 30 символів, наприклад: `g89x2n41a7b...`).

> ⚠️ **Важливо**: Нікому не передавайте свій `auth-token`! Він дає доступ до вашого акаунта Twitch.

## 🚀 Налаштування та Прошивка

### 1. Компіляція та Прошивка (PlatformIO)

1. Встановіть розширення **PlatformIO IDE** у VS Code.
2. Відкрийте папку проєкту у VS Code.
3. Підключіть плату **ESP32-S3** через порт **USB** (CDC).
4. Натисніть кнопку **Upload** (стрілка внизу в панелі PlatformIO) або виконайте в терміналі:
   ```bash
   pio run --target upload
   ```

## ⚙️ Налаштування пристрою

Встановити Wi-Fi та OAuth токен можна **двома способами**:

### Спосіб 1: Через Web-інтерфейс (Рекомендовано)

1. При першому запуску (або якщо Wi-Fi не налаштовано) ESP32 створить Wi-Fi точку доступу:
   - **SSID**: `ESP32-Twitch-Farmer`
   - **Пароль**: `12345678`
2. Підключіться до цієї мережі з телефону або ПК.
3. Браузер автоматично відкриє сторінку налаштувань (або перейдіть за адресою `http://192.168.4.1`).
4. Введіть:
   - Назву вашої Wi-Fi мережі (SSID) та пароль.
   - Скопійований **Twitch OAuth Token**.
   - Назву гри (наприклад: `Rust`, `Valorant`, `CS:GO`, `Apex Legends`).
   - (Опціонально) Нікнейм конкретного стримера.
5. Натисніть **Save & Update Settings**. ESP32 збереже налаштування в энергонезалежну пам'ять (NVS) та підключиться до вашого Wi-Fi.

### Спосіб 2: Через USB Serial CLI

Відкрийте Serial Monitor на швидкості `115200` та використовуйте текстові команди:

| Команда | Опис | Приклад |
| :--- | :--- | :--- |
| `1` або `status` | Переглянути поточний статус, IP, прогрес та стан PubSub | `status` |
| `2` або `wifi <ssid> <pass>` | Налаштувати Wi-Fi мережу | `wifi MyHomeWiFi SecretPass123` |
| `3` або `token <token>` | Встановити Twitch OAuth токен | `token g89x2n41a7b...` |
| `4` або `game add <name> [prio]` | Додати гру до черги (опціонально вказати пріоритет) | `game add Rust 1` |
| `game priority <name> <val>` | Встановити точний пріоритет для гри | `game priority Rust 1` |
| `game up <name> [steps]` | Підняти гру в черзі на N позицій (за замовчуванням: 1) | `game up Rust 2` |
| `game down <name> [steps]` | Опустити гру в черзі на N позицій (за замовчуванням: 1) | `game down Rust 2` |
| `game remove <name>` | Видалити гру з черги | `game remove Rust` |
| `game list` | Показати поточну чергу ігор | `game list` |
| `game clear` | Очистити всю чергу ігор | `game clear` |
| `5` або `channel <login>` | Встановити конкретного стримера (або порожньо для авто) | `channel shroud` |
| `6` або `scan` | Сканувати доступні Wi-Fi мережі | `scan` |
| `7` або `start` / `stop` | Увімкнути / Вимкнути цикл фарму | `start` |
| `8` або `claim` | Примусово оновити інвентар та забрати дроп | `claim` |
| `9` або `reset` | Скинути налаштування до заводських | `reset` |
| `10` або `reboot` | Перезавантажити ESP32-S3 | `reboot` |

## 📊 Як перевірити статус фарму

- **Через Web-панель**: Відкрийте IP-адресу ESP32 у браузері (наприклад `http://192.168.1.150`). Панель показує активний дроп, відсоток прогресу, накопичені хвилини, зібрані дропи та логи у реальному часі.
- **Через Serial Monitor**: Надішліть команду `status` або `1`.

## ❓ Вирішення проблем (Troubleshooting)

- **`PubSub WebSocket: Disconnected`**:
  Перевірте, чи правильно вказано OAuth токен та чи є стабільне підключення до інтернет.
- **`Heartbeat rejected or empty response`**:
  Токен застарів або вказано невірного стримера. Оновіть `auth-token` з браузера.
- **Прогрес не нараховується**:
  Переконайтеся, що для даної гри/стримера на Twitch в даний момент активна кампанія Drops.
